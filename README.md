# Oak Creators Frontend

This is the frontend application for Oak Creators, built with [Next.js](https://nextjs.org). 

## Getting Started

First, install dependencies:
```bash
npm install
# or
yarn install
```

## Environment Variables

To connect this frontend to the local backend during development, create a `.env` file in the root directory:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```
*(If your backend runs on a different port, update the URL accordingly)*

## Running the Application

Run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
